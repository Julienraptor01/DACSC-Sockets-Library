## Dev Setup

1. Clone the project
1. Go to the project directory
1. Exclude the `.vscode` folder from version control changes
1. Setup the project

```bash
git clone https://github.com/Julienraptor01/DACSC-Sockets-Library.git
cd DACSC-Sockets-Library
git update-index --skip-worktree .vscode/*
make setup
```

## Build

1. Build the project
1. Run the test binaries

```bash
make build
make run-test
```
